## 🏗️ Architecture Overview

SkillSphere moves beyond traditional freelance platforms by integrating **hyperlocal discovery**, **AI skill-matching**, and **enterprise-grade security** into a seamless full-stack ecosystem.

| 🧠 **AI Engine** | 🛡️ **Security & Auth** | 💬 **Real-Time Core** | 💰 **Financial System** |
|:----------------:|:----------------------:|:---------------------:|:-----------------------:|
| HuggingFace Models | JWT + 2FA + RBAC | Socket.IO + WebRTC | Razorpay/Stripe Escrow |
| Skill Similarity | Google OAuth + Email | Instant Chat + Files | Milestone Payouts |
| Fraud Detection | Token Reset + RBAC | Typing Indicators | Refund & Dispute Mgmt |

---

## ✨ Advanced Feature Modules

### 🔐 1. Multi-Role Authentication System
- ✅ **Role-Based Access Control (RBAC)**: Client, Freelancer, Admin
- 🔑 **Secure Auth Flow**: JWT, Google OAuth, Email Verification, Password Reset Tokens
- 🛡️ **2FA Integration**: Time-based One-Time Password (TOTP)

### 🤖 2. AI-Powered Job Matching Engine
- 🎯 **Smart Gigs Recommendation**: Matches clients with top local talent using skill similarity scoring
- 📈 **Trending Skills Detection**: Real-time market demand analytics
- ⚙️ **Example**: Client posts `React Developer` → AI recommends highest-rated local freelancers with exact tech stack match

### 👤 3. Professional Freelancer Profiles
- 📊 **Dynamic Portfolio**: Gallery, Resume Upload, Certifications, Work Experience Timeline
- 📅 **Availability Calendar**: Slot booking & auto-scheduling
- 💵 **Flexible Pricing**: Hourly & milestone-based rate configuration
- 🏅 **Verification Badges**: Identity & skill verification system

### 🛒 4. Gig & Project Marketplace
- 📝 **Rich Gig Creation**: Budget ranges, milestone definitions, document attachments
- 🤝 **Freelancer Engagement**: Apply, submit proposals, track status in real-time
- 📊 **Progress Tracker**: Task completion %, progress logs, deadline reminders

### 💬 5. Real-Time Chat & Collaboration
- 🌐 **WebSocket Powered**: Instant messaging via Socket.IO
- 📎 **Rich Media**: File sharing, typing indicators, read receipts
- 🎥 **Video Integration**: WebRTC-ready architecture for live calls

### 💳 6. Secure Payment & Escrow System
- 🔒 **Escrow Protection**: Funds held securely until milestone completion
- 💸 **Automated Payouts**: Seamless freelancer payouts via Razorpay / Stripe
- 📜 **Transaction Ledger**: Complete financial history & refund management

### 📈 7. Smart Reputation & Analytics
- ⭐ **Weighted Scoring**: Verified reviews with anti-fake review algorithms
- 📉 **Admin Dashboard**: User management, fraud monitoring, platform revenue, top categories
- 📊 **Freelancer Analytics**: Profile views, application rates, monthly revenue charts, client feedback trends

##⚙️ Setup & Installation

### 📋 Prerequisites
```bash
Node.js ≥ 18.x
npm ≥ 9.x or yarn ≥ 1.22.x
MongoDB Atlas cluster
Razorpay/Stripe merchant account
```

### 🛠️ Quick Start

#### 1. Clone the repository
```bash
git clone https://github.com/Bhawana0218/SKILLSPHERE-.git
cd skillsphere
```
#### 2. Install dependencies
```bash
npm run install-all
```
#### 3. Configure Environment (see below)
```bash
cp server/.env.example server/.env
cp client/.env.example client/.env
```
#### 4. Run Development Servers (Concurrently)
```bash
npm run dev
```

```text
🌍 Frontend: http://localhost:5173
🔙 Backend: http://localhost:5000
```

## 🔑 Environment Configuration

#### server/.env

```bash 
PORT=5000
MONGO_URI=mongodb+srv://<user>:<pass>@cluster.mongodb.net/skillsphere
JWT_SECRET=your_super_secret_jwt_key
JWT_REFRESH_SECRET=your_refresh_secret
GOOGLE_CLIENT_ID=your_google_oauth_id
GOOGLE_CLIENT_SECRET=your_google_oauth_secret
RESEND_API_KEY=your_resend_email_key
RAZORPAY_KEY_ID=your_razorpay_id
RAZORPAY_KEY_SECRET=your_razorpay_secret
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
HF_API_TOKEN=your_huggingface_token

```

#### client/.env
```bash
VITE_API_BASE_URL=http://localhost:5000/api
VITE_SOCKET_URL=http://localhost:5000
VITE_GOOGLE_CLIENT_ID=your_google_client_id
```

## 🚀 Deployment Guide
```text
Frontend: Deploy to Vercel or Netlify. Configure VITE_API_BASE_URL to point to your production backend.
Backend: Deploy to Render, Railway, or AWS Elastic Beanstalk. Set environment variables securely.
Database: Use MongoDB Atlas with IP whitelist or VPC peering for production security.
Storage: Configure Cloudinary or AWS S3 for resume & portfolio media uploads.
```
